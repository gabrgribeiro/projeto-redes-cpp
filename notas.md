# Notas

## Dia 1: Instalações
- Instalação do `WSL` (`Windows Subsystem for Linux`) via **PowerShell**.

## Dia 2: Shell
- O comando `cd` permite alterar de diretório.
- `ls` ou `dir` listam o conteúdo do diretório.
- `mkdir` cria um novo diretório.
- `ni` ou `touch` cria novos arquivos.
  - `ni` (`New-Item`): Usado no **PowerShell**, Windows.
  - `touch`: usado no **Ubuntu (WSL)**, Linux.
- `rm` exclui arquivos.
- `>` cria ou sobrescreve um arquivo; `>>` acrescenta uma linha no final do arquivo.
- `cat` exibe o conteúdo de um arquivo.
- `chmod +x` dá permissão de execução ao arquivo.
